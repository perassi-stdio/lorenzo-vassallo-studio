# Lorenzo Vassallo Studio

Landing editoriale statica (HTML / CSS / JS vanilla, nessuna dipendenza).

## Avvio

Dalla cartella `lorenzo-vassallo-studio/`:

```bash
python3 -m http.server 8000
```

Poi apri `http://localhost:8000`.

## Struttura

- `index.html` — markup e copy originale di `copy.md`
- `css/style.css` — design system, composizioni, motion, responsive, reduced-motion
- `js/main.js` — reveal, stato dello sticky, parallasse, menu, form demo
- `assets/` — fotografie autentiche rinominate (riferimento, da autorizzare)

## Regola anti-AI

Nessun eyebrow decorativo, emoji non presente nel copy, badge, gradiente,
glassmorphism, ombra decorativa, radius eccessivo, card ripetitiva, icona,
pill, separatore inutile, layout SaaS, hero template o animazione senza
funzione. Nessuna freccia `⬇️` è presente nella pagina: le due frecce del copy
originale restano solo in `copy.md`.

## Note sul copy

Il testo strategico, le headline e le CTA provengono da `copy.md`. Su richiesta
sono stati rivisti i testi delle tre motivazioni e le FAQ, ora basate sulle otto
domande selezionate. La numerazione editoriale (01/02/03) e le didascalie
`stile 1` / `stile 2` riprendono la struttura del documento originale.

## Note per la revisione

- Le immagini provengono da Instagram: usate solo come riferimento in questa bozza locale.
- Il form di contatto è dimostrativo: non invia dati.
- Palette limitata a neutri: il colore visivo viene dalle fotografie.
